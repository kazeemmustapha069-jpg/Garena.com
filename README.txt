# VEXORA — Gaming Marketplace Demo

## Open in VS Code
1. Extract `VEXORA.zip`.
2. Open the `VEXORA` folder in Visual Studio Code.
3. Open `index.html`.
4. Run it with the Live Server extension (or open the HTML file in a browser).

## Project files
- `index.html` — page structure and content
- `style.css` — responsive dark/neon styling
- `script.js` — game selection, package prices, order preview and mobile menu
- `images/` — local artwork used by the website

## Important
This is a front-end demonstration only. The displayed package prices are sample values, not verified live prices. The order preview does not accept payment, contact a supplier, or deliver game credits. Do not add real payment collection until a secure backend, verified supplier process, clear refund policy and appropriate adult supervision are in place. Never ask customers for game passwords or OTPs.
